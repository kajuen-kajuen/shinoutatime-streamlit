# ユーザーガイド

「しのうたタイム」は、VTuber「幽音しの」さんの配信で歌われた楽曲を探せる非公式ファンサイトです。このガイドでは、各ページの使い方を説明します。困ったときは [よくある質問](../faq.md) もご覧ください。

ページは左のサイドバーで切り替えます。

| サイドバーの名前 | ページ |
|---|---|
| Home | 歌唱の検索(このサイトの中心) |
| Information | 予定表の動画、今週のスケジュール、お知らせの案内 |
| About Us | このサイトについて |
| Song List beta | 歌唱楽曲リスト(β版) |

どのページも、上に見出し「しのうたタイム👻🫧」、下(フッター)に連絡先 [@kajuen_kajuen](https://x.com/kajuen_kajuen) があります。

## Home(歌唱の検索)

### ページの構成

1. 見出しと、楽曲リストへの案内、サイトの説明
2. データの時点: 「データは YYYY/MM/DD の配信まで(歌唱 N 件)」。この日付までの配信が登録されています
3. 検索欄: キーワード、「検索対象にライブ配信タイトルを含める」のチェック、「検索」ボタン
4. 結果の表
5. 「さらに25件表示」ボタン

### 結果の表

開いたときは、すべての歌唱が新しい順に25件出ます。

| 列 | 内容 |
|---|---|
| 配信日 | 歌った日(例: 2026/10/20) |
| No. | その配信の中で何曲目か(下の「No. の見方」) |
| 曲名 | 一部だけ歌ったときは尺を後ろに付けます(例: 「曲名(1chorus)」) |
| アーティスト | 作り手。歌い手が別にいる曲は「作り手 feat.歌い手」 |
| 種類 | 歌った場所: 配信・ショート・動画・投稿(X など) |
| リンク | 歌ったところへのリンク(下の「リンク」) |

メンバー限定の配信は載せていません。

#### No. の見方

- 「3」: その配信の3曲目
- 「1-3」: 同じ日にライブ配信が複数あるとき、1つ目(時刻の早い方)の配信の3曲目
- 空欄: 1曲だけのショートや動画

#### 並び順

1. 配信日の新しい順
2. 同じ日に複数あるときは、時刻の早い順
3. 1つの配信の中は、歌った順

### 検索のしかた

1. 検索欄に曲名かアーティストを入れます。
2. Enter キーを押すか、「検索」ボタンを押します。
3. 「「キーワード」で検索した結果: N件」と出て、表が絞り込まれます。

検索のポイント:

- 部分一致です。「夜に駆ける」なら「夜に」「駆ける」でも当たります。
- 全角と半角、大文字と小文字、カタカナとひらがな、空白の有無は区別しません。
- 曲名・アーティストの読みでも当たります(例: 「かいじゅう」で「怪獣の花唄」)。
- 「検索対象にライブ配信タイトルを含める」にチェックを入れると、配信のタイトルも対象になります(例: 「歌枠」「耐久」「記念」)。結果は多くなります。

一覧に戻すには、検索欄を空にしてもう一度検索します。

### さらに表示

表の下の「さらに25件表示(現在の表示: 25/150件)」を押すと、25件ずつ増えます(件数は例です)。全部出ると「全ての150件が表示されています。」に変わります。

### リンク

| 文言 | 開くところ |
|---|---|
| YouTubeへ👻 | YouTube の配信・動画。歌い始めの時刻から再生されます(例: `https://www.youtube.com/watch?v=VIDEO_ID&t=1234s` は 20分34秒から) |
| Xへ👻 | X の投稿。時刻は指定できません |
| Z-aNへ👻 | Z-aN のページ。時刻は指定できません |

リンクは新しいタブで開きます。

## Song List beta(歌唱楽曲リスト(β版))

これまでに歌った曲を、1曲1行で一覧にしたページです。

- 列: アーティスト・曲名・リンク。上に「全 N 件」と出ます。
- 並び順: アーティストの読みの順 → 曲名の読みの順(記号・数字、英字、かなの順)
- リンク: その曲をいちばん最近歌ったところ(切り抜きを除く)
- 表示: Home と同じく25件ずつ。「さらに25件表示」で増えます。
- 特定のアーティストを探すときは、ブラウザのページ内検索(Ctrl+F / Cmd+F)が便利です。曲を探すなら Home の検索が向いています。

β版なので、今後レイアウトや機能が予告なく変わることがあります(ページ上部の「β版の制約について」)。

## Information

- **ふりちゃという名の予定表置き場**: 配信の予定表の動画(YouTube)をページ内で見られます。
- **今週のスケジュール**: 本人の X の「今週のスケジュール」の投稿です。毎週更新します。表示が古いときや出ないときは、本人の X で確かめてください。
- **お知らせ・グッズ・活動の記録**: ななしいんく 非公式Wiki の幽音しののページ、本人の X、公式サイトへのリンクです。お知らせ・グッズ・これまでの活動・オリジナル曲の一覧は、そちらで確かめてください。
