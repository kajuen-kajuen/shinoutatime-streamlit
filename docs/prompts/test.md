## 守るべきものの優先順位

1. データの読み込みと結合 — `data/v2/` の TSV の列・文字コード、外部キーの結合で行が落ちないこと、壊れたファイルで例外(`DataLoadError`)になること(`TableRepository`・`src/ui/v2_data.py`)
2. 表示用の加工 — No. の番号付け(同じ日に複数配信があるときの `1-3` 形式、1曲だけのショートは空欄)、配信日の表示形式、YouTube のタイムスタンプ付き URL、尺付きの曲名、メン限を出さないこと(`src/core/views.py`)
3. 検索 — 正規化(全角・カタカナ・見えない文字)・読みで当たること・配信タイトルを含めるかどうか・空の検索語(`home_page.filter_view`)
4. 曲ごとの集計(`build_song_stats`)— 切り抜きを数えないこと、最新の歌唱の選び方、アーティストの読みの順
5. ページ — 各ページが例外なく起動すること、データが読めないときにエラー表示で止まること、さらに表示(e2e)

v2 のデータと取り込み(`tests/unit/v2`)で守るもの:

1. 検査と読み書き — 主キー・外部キー・値の形・並び順の検査(`src/core/validation.py`)、検査を通ったときだけ保存すること、任意の列が無い古いファイルも読めること(`TableRepository`)
2. 集計 — `views.build_performance_view`(No. と枝番、メン限を出さない、演奏の形、リンク、検索用の列)と `build_song_stats`(切り抜きを数えない)
3. 取り込みの解析 — 職人さんのコメントの選び方、時刻の行の分け方、曲名の注記(part・note)、feat. の分け方、既存の曲との照合(`src/ingest/parser.py`)、追記(`staging.apply_staged`)
4. YouTube API — 失敗のメッセージにキー・URL を入れないこと、上限で次のキーへ切り替えること、メン限・コメント不可の動画をコメント0件で取ること(ネットワークには出ずモックで)
5. 性能 — 架空の2万件で、読み込みから集計まで約0.5秒(`tests/performance`、`--runslow`)。集計や読み込みを変えたときに流す

## 制約

- テストの期待値は仕様(`_common-context.md`・`docs/specs/`)を根拠にする。今の実装の出力をそのまま期待値にしない
- テストのために本番コードを変えるときは、振る舞いを変えない最小のリファクタリングに留める
- テストの依存を新しく足さない(足したくなったら聞く)。ネットワークに出るテストを書かない(モックで)
- `data/` の本物の TSV を書き換えるテストを書かない。書き込みは `tmp_path` に

## 止まって聞く所

1. 対象がテスト可能な形になっていないとき(ページのトップレベルに処理が書かれているなど)。最小のリファクタリング案を出して承認を待つ
2. **テストケース一覧を出したあと**。承認を待ってから実装する

## 決めてよいこと・聞くこと

| 決めてよい | 聞く |
|---|---|
| テストの命名・配置(既存の `tests/` の並びに合わせる) | 本番コードの変更(最小のリファクタリングでも) |
| 境界値・異常系の追加、`tests/fixtures/` への小さなデータの追加 | 期待値が仕様書に無いとき(【要確認】にする) |
| 古い前提のテストを、今の仕様(例外を投げる)に合わせて直す | テストを消す・スキップする |

## 手順

1. 仕様(データ形式・エラー処理の方針・表示の決まり)をテストの期待値の根拠として整理する。完了条件: 対象ごとに根拠の仕様書の節
2. 対象ロジックがテスト可能な形になっているか確認する。テスト不能なら【止まる】最小のリファクタリング案を提示
3. 優先順位の高いものから、正常系・境界値・異常系のテストケース一覧を提示する
4. 【止まる】一覧の承認を待つ
5. テストを実装する。完了条件: `_commands.md`「テスト(全部)」で全件パス
6. 仕様書のテストの節に足し、テスト規約(`_common-context.md`)に追記が要るなら案を出す

## 出力形式

- テストケース一覧表(対象/ケース/期待値/種別(unit・property・integration・e2e)/根拠の仕様書の節) → 実装 → 実行結果(実際の出力)
- カバーできなかったリスクと、ブラウザで確認すべき項目のチェックリスト
