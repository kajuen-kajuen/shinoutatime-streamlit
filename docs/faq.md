# よくある質問(FAQ)

画面の使い方は [ユーザーガイド](guides/user-guide.md) にまとめています。

## サイトについて

### Q1: 「しのうたタイム」とは何ですか?

VTuber「幽音しの」さんの配信で歌われた楽曲を、曲名やアーティストで探せる非公式ファンサイトです。リンクから、その曲を歌い始めたところへ直接飛べます。

### Q2: 公式のサイトですか?

いいえ。ファンが有志で作っている非公式サイトで、幽音しのさんご本人・所属事務所とは関係ありません。公式の情報は、[公式サイト](https://www.774.ai/talent/shino-kasukane)・[YouTube](https://www.youtube.com/@Shino_Kasukane)・[X](https://x.com/Shino_Kasukane_) をご確認ください。

### Q3: スマートフォンでも使えますか?

使えます。表が画面の幅に収まらないときは、表を横にスクロールしてください。

## 検索について

### Q4: 検索しても見つかりません

- キーワードを短くしてみてください。部分一致なので、「夜に駆ける」なら「駆ける」でも当たります。
- 読みでも探せます。曲名・アーティストのひらがなの読みも検索の対象です(例: 「かいじゅう」で「怪獣の花唄」)。
- 「検索対象にライブ配信タイトルを含める」にチェックを入れると、配信のタイトルでも探せます(例: 「歌枠」「耐久」)。
- まだ登録されていない配信かもしれません。Q10 を見てください。

### Q5: 全角・半角やカタカナ・ひらがなの違いは区別されますか?

区別しません。次の違いはすべて同じとして探します。

- 全角と半角(「ＹＯＡＳＯＢＩ」と「YOASOBI」)
- 大文字と小文字(「yoasobi」と「YOASOBI」)
- カタカナとひらがな(「カイジュウ」と「かいじゅう」)
- 空白の有無(「夜に 駆ける」と「夜に駆ける」)

検索は、キーワードを入れて Enter キーを押すか、「検索」ボタンで始まります。

### Q6: 検索結果はどんな順に並んでいますか?

1. 配信日の新しい順
2. 同じ日に複数あるときは、時刻の早い順
3. 1つの配信の中は、歌った順

### Q7: 検索をやめて全部の一覧に戻すには?

検索欄を空にして、もう一度検索してください。ページを再読み込みしても戻ります。

## 表の見方とリンク

### Q8: 「No.」の「1-3」や空欄は何ですか?

その配信の中で何曲目かを表します。

- 「3」: その配信の3曲目
- 「1-3」: 同じ日にライブ配信が複数あるときの、1つ目(時刻の早い方)の配信の3曲目
- 空欄: 1曲だけのショートや動画(何曲目かを付ける必要がないため)

### Q9: 「種類」の列や、曲名の後ろの「(1chorus)」は何ですか?

- 種類: 歌った場所です。配信・ショート・動画・投稿(X など)があります。
- 曲名の後ろの括弧: 一部だけ歌ったときの尺です(例: 「(1chorus)」)。

### Q10: どの配信まで登録されていますか? どのくらいで更新されますか?

Home の検索欄の上に「データは YYYY/MM/DD の配信まで(歌唱 N 件)」と出ています。その日付までの配信が登録されています。

データは、タイムスタンプ職人さんのコメントや X の投稿をもとに、有志が確かめて登録しています。更新は不定期で、まとめて行います。

### Q11: リンクを押すと、曲の途中から再生されます

正常な動きです。YouTube のリンクには歌い始めの時刻が付いているので、その曲のところから再生されます。

X(「Xへ👻」)と Z-aN(「Z-aNへ👻」)のリンクは時刻を指定できないので、投稿やページが開くだけです。歌っているところは、ご自身で探してください。

### Q12: リンクを押しても再生できません

- 配信のアーカイブが削除・非公開になった可能性があります。
- メンバー限定の配信は、このサイトに載せていません。

## 楽曲リスト(β版)

### Q13: 楽曲リストはどんな順に並んでいますか?

1曲を1行にして、アーティストの読みの順 → 曲名の読みの順に並べています。記号・数字、英字、かなの順です。

リンクは、その曲をいちばん最近歌ったところ(切り抜きを除く)に飛びます。β版なので、今後レイアウトや機能が変わることがあります。

## データの誤り・連絡

### Q14: 曲名やアーティストの誤りを見つけました

各ページの下(フッター)にある連絡先 [@kajuen_kajuen](https://x.com/kajuen_kajuen) までお知らせください。

データの正確さは保証できません。正確な情報は、公式チャンネルや配信のアーカイブでご確認ください。

## 技術的なこと

### Q15: 何で作られていますか? ソースは公開されていますか?

Python 3.14・[Streamlit](https://streamlit.io/)・pandas で作り、Streamlit Community Cloud で公開しています。データは TSV のファイルです(リポジトリの `data/v2/`)。

サイトのソースは [GitHub](https://github.com/kajuen-kajuen/shinoutatime-streamlit) で公開しています(Apache License 2.0)。データの取り込みの道具・テスト・開発用の資料は公開していません。
